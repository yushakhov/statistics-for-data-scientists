# Практическая статистика для специалистов по данным (Реализация на Python)

Код, относящийся к книге "Практическая статистика для специалистов по данным: 50 основных концепций", переведенный на язык Python.

Скрипты на Python сгруппированы по главам в директории `python_src` и воспроизводят большинство графиков и фрагментов кода из оригинального R-кода.

# КАК ИСПОЛЬЗОВАТЬ

## Данные

Данные не хранятся на GitHub. Вам потребуется сначала их скачать.

Это можно сделать, запустив скрипт Python:

```bash
python python_src/download_data.py
```

Этот скрипт загрузит необходимые файлы с данными в директорию `data` внутри папки проекта.

## Зависимости

Скрипты требуют наличия нескольких библиотек Python. Вы можете установить их с помощью `pip`:

```bash
pip install -r requirements.txt
```

## Запуск скриптов

Скрипты предполагают, что репозиторий был клонирован в вашу домашнюю директорию (`~/statistics-for-data-scientists`). Если вы сохранили репозиторий в другом месте, вам потребуется отредактировать следующую строку в каждом скрипте:

```python
PSDS_PATH = os.path.join(os.path.expanduser('~'), 'statistics-for-data-scientists')
```

чтобы она указывала на правильный путь к директории.

Оригинальные R-скрипты для этой книги можно найти в репозитории автора: https://github.com/gedeck/practical-statistics-for-data-scientists
